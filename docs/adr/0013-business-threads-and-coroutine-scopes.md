# 业务线程与协程作用域

Swoole 业务线程拥有独立运行时、容器和连接池，请求与任务拥有独立执行作用域，普通受管子任务在线程内使用协程。进程提供故障和信号边界，线程提供并行执行边界，协程提供同一线程内的合作式 I/O 并发；执行方式可按目标构建能力降级，但每次降级都必须重新核对隔离、停止和资源总额。

执行作用域保存本次工作的关联上下文、单调截止时间、取消意图和任务预算。上下文只承载有界的字符串标识；创建受管子任务时复制上下文，子任务取得新的协程所有者，同时共享只能缩短的截止时间、取消信号和执行树预算。连接、事务、结果流和其他可变资源不随上下文复制，必须在子作用域内重新借用。

资源归属按进程、原生线程、请求代次、Swoole 协程和 Fiber 身份校验。协程切换不能把父任务资源带到子任务，`await` 超时只发送取消意图，不代表底层操作已经退出；作用域保持 closing 并继续持有预算，直到真实收尾后才进入 closed。这个选择以资源归属清晰换取可控并行，接受运行状态重复与局部额度闲置的代价。
