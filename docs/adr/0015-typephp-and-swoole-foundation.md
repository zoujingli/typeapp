# 编译工具与原生运行库的职责

TypeApp 通过组件向应用提供能力。TypePHP 仅在构建期编译生产 PHP 实现；Swoole 作为内置原生运行库提供通信、进程、线程、协程和事件循环，随应用交付。选择官方运行机制是为了复用网络与并发实现，减少自维护调度器和平台适配的成本。

框架负责显式装配、编译入口、PHP ZTS/PHPX 生命周期、执行作用域、资源预算和业务语义。必要原生适配须具有固定版本的实证缺口和撤除条件。原生运行库不作为 PHP 源码交给 TypePHP 编译，构建工具也不进入生产请求链。具体规则见[Swoole 复用标准](../standards/swoole-reuse.md)。
