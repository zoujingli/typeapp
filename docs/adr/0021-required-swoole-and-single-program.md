# Swoole 唯一底层与单程序交付

Swoole 是随应用交付的内置原生运行库。通信与基础并发必须采用其官方能力，直接沿用官方 API 与配置；进程不可用时使用官方线程或协程，重新验证隔离与停止语义。

生产交付约定为一个主程序文件加外置配置。PHPX、libphp、Swoole 及其他非系统原生库在构建期静态链接进程序，启动不释放运行库；允许依赖目标操作系统自带库。部署者无需安装 PHP、Swoole、Composer 或编译工具，业务所需的数据库服务、证书和持久数据仍独立管理。该取舍将版本与 ABI 管理集中到构建端，以减少现场环境装配。

组件内置共享模块用于复用构建输入，不能证明完整静态链接完成。当前目录包与最终交付的差距见[构建与部署](../guide/deployment.md#当前构建状态)，验收工作见[实现规划](../guide/roadmap.md)。
