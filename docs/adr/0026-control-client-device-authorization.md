# 双端管理与设备通信授权

状态：已决定，待实施，2026-10-22。

物联中心采用同一部署中的控制端与客户端，两端拥有独立登录、工作区和 RBAC，复用已有人员身份与框架组件，以保持平台管理和客户范围清晰而无需部署两套后台。控制端统一签发并分配设备注册授权，客户端管理本客户获授权设备、独立接入应用及应用密钥，通信权限绑定应用与设备使用关系并分别控制接收、发送和订阅，避免把人员权限、注册资格和通信权限混为一体。业务范围收敛到客户管理、设备授权、接入和原始通信，移除处理器及遥测、历史、统计、告警和业务指令编排，使业务系统负责载荷语义与处理结果。

这是新的业务目标，不代表现有数据处理链已经移除；实施和数据迁移前仍按当前合同运行，通用协议能力及历史验收证据保持各自边界。职责、迁移与验收见[控制端与客户端设计](../development/iot-control-client-design.md)，现有人员授权与模拟登录规则继续遵循[双端 RBAC](0017-dual-realm-tenant-rbac.md)和[真实管理身份保留](0018-admin-customer-impersonation.md)。
