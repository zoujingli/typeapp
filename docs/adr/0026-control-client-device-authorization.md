# Platform / System / Center 与原始通信

状态：已决定，当前开发源码重构与候选验收中，2026-11-14。

物联中心采用单程序、多运行角色：Platform 管理平台人员、Tenant、客户超管、公共菜单、注册资格签发、全局设备资产及 MQTT 运维；System 管理当前 Tenant 的人员、角色、会话与品牌，Center 共用其身份并管理本客户设备、接入应用和原始通信。独立 Broker 人员后台退出，保留协议及持久存储运行角色；设备权限绑定接入应用和当前使用关系，分别控制接收、发送与订阅，载荷业务语义由外部业务系统负责。

采用全新安装，旧安装拒绝接入且不自动清库，不维护旧人员入口、跨客户成员关系或数据转换分支；这是以统一身份和隔离边界取代旧部署兼容的明确取舍。源码实施、PHP 三库、浏览器、完整 AOT、无源码运行和正式平台矩阵分别验收，旧版证据不证明当前候选完成；身份和入口说明见[身份与授权](../development/iot-identity.md)，授权与模拟规则遵循[独立身份决策](0017-dual-realm-tenant-rbac.md)和[真实管理身份保留](0018-admin-customer-impersonation.md)。
