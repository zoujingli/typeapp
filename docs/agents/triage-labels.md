# 标签词汇

采用 Matt 技能默认角色，机器标识保留英文，含义和仓库描述使用中文。

| 角色 | GitHub 标签 | 中文含义 |
| --- | --- | --- |
| 等待评估 | `needs-triage` | 维护者需要评估需求 |
| 等待信息 | `needs-info` | 缺少实施必需的信息 |
| 可由代理实施 | `ready-for-agent` | 规格明确，可在阻塞解除后领取 |
| 需要人工处理 | `ready-for-human` | 需要人工判断、操作或实施 |
| 不予实施 | `wontfix` | 明确不在实施范围内 |

分类沿用 `bug`（缺陷）和 `enhancement`（功能或改进）。显式运行 triage 时使用一个分类角色和一个状态角色；to-spec/to-tickets 按各自流程发布 `ready-for-agent`，不回头重标父规格。

同一任务的状态角色应唯一；原生阻塞关系独立于标签记录。任务仍有阻塞时不会因标签为 ready-for-agent 自动开始。

运行 triage 技能自动发表分诊说明时，按该技能要求标明 AI 生成；中文表述为“此内容由 AI 在需求分诊过程中生成”。具体技能原文与用户约定冲突时以当前会话指令为准。
