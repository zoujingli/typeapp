# 构建拒绝用例的真实依赖

`tests/build-errors.php` 的无声明依赖用例改为实际安装的 `nikic/php-parser`。该包由 type-build 的开发工具链安装，有真实 Composer 元数据和自动加载源码，但没有应用生产编译声明；将它加入临时项目生产依赖后，构建入口必须明确报告 `生产依赖缺少支持的编译声明：nikic/php-parser`。

原用例的 `psr/log` 已获得 type-log 提供的合法完整适配，不能继续把它当作无声明依赖。测试先核实 php-parser 确实安装且没有自身编译声明，再运行真实构建命令，依赖检查拒绝后继续核实原有产物内容未改变。
