## 限制与后续验收

本机结果只覆盖 macOS ARM64。Linux x64、Linux ARM64、Windows x64 的本轮结果及 17 个 Release、16 个子仓标签、16 个 Packagist 版本须由远端真实运行另行记录。浏览器补验覆盖上述业务闭环，不等同于逐项操作所有管理页面。

当前附件仍是包含原生运行库的目录归档；页面在显式安装时写到 `public/`，普通启动不释放资源。完整静态单程序目标未完成。Windows 现有部署隔离也不等同于 macOS/Linux 的强制拒绝工具访问边界。
