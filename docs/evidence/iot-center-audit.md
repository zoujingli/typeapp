## 本次修复

1. **站点设置整页保存返回 500。** 页面一次提交19个字段，控制器将字段名拼入最多100字节的审计 `reason`，导致事务回滚。改为配置事件专用的 `changed_fields`，只允许字段名清单、最多4096字节，保留全部键名及版本，不记录配置值。运行配置使用同一机制，验证大写环境键的批量保存。
2. **并发冲突丢失输入。** 站点页现在按错误状态识别409，保留输入并禁止旧版本再次提交，用户明确刷新后恢复。尚未成功读取设置、读取中或保存中均禁用编辑和保存，避免把界面初值写到已有站点。
3. **默认品牌消失、标题固定。** Logo地址为空时保留 Vben文字品牌；动态标题读取路由和站点名称，并保留“物联开源分享”。窄屏标题和按钮允许换行，表单标签关联真实控件。
4. **测试漏接公开设置。** 共用浏览器预览加入 `/public/` 代理，避免启动失败后默认值掩盖真实品牌读取。租户冲突装置改为真实修改名称，不再依赖相同值保存推进 Model 版本。
5. **文档过时。** 补齐默认数据、站点保存时序图及真实界面边界，清除 Web README 的失效规格/任务链接和已过期开放范围，更新 Docsify 搜索命名空间。
