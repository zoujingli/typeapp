# Windows 发布契约修复记录

RC16 的 [正式发布运行](https://github.com/zoujingli/typeapp/actions/runs/38821654510)在 Windows 公开契约检查失败，主仓版本未公开。标签 `v1.0.0-rc.16` 固定源码 `1386d9af43ba746b8804111159cc8e4d358abecf`，不得移动；本记录只证明以下定向修复，不替代 RC17 的完整发布验收。

## 复现与修复

原源码在相同 PHP 8.5.10 ZTS、锁定 Swoole 的 Windows 2022 环境中，仅运行五项相关测试即可稳定复现：3 个错误、2 个失败，耗时 0.400 秒。入口与原始结果见[最小复演运行](https://github.com/zoujingli/typeapp/actions/runs/38828668881)。

| 失败 | 根因 | 修正与保留边界 |
| --- | --- | --- |
| MySQL、PostgreSQL profile 保存无关配置被拒绝 | 测试仍以空字符串模拟删除环境变量；运行库已经支持标准删除，空值仍是有效的进程覆盖 | 测试通过不带等号的 `putenv()` 删除并断言未设置，恢复原值；业务配置对进程覆盖的只读限制保持不变 |
| Model 与 Service 同文件转换后重复声明 | 生成目录沿用 Windows 原始分隔符，下游编译器返回统一分隔符，替换集合未能移除前一份生成源码 | 复用 `BuildPlatform::path()` 统一输出路径身份；继续拒绝跳转、符号链接和真实重复声明 |
| 冻结 Schema 路径断言失败 | 测试比较混合分隔符的输入路径与已规范化的公开结果 | 以实际规范路径比较，不改变冻结文件内容或清单协议 |
| 快照链接夹具未建立 | Windows 文件链接创建需要已存在的目标，旧夹具指向不存在的文件 | 使用独立的真实目标验证链接拒绝，并核对目标字节未变；仍执行全部非法声明和篡改拒绝 |

环境语义另用[五组原生探针](https://github.com/zoujingli/typeapp/actions/runs/38828670387)核对：裸 PHP、基础扩展、Swoole、完整配置和显式 UTF-8 均通过删除、写入和子进程继承检查。生产继续保留 `configuration_field_read_only` 对进程覆盖配置的保护。
