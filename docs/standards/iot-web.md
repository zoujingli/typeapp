# 物联网中心 Web 页面标准

本标准适用于物联中心的 Platform 平台管理端，以及 Tenant 内的 System、Center 工作区。通用 UI 优先直接复用 Vben 的组件、样式与配置机制，以锁定依赖的公开接口为准；应用补充业务字段、接口、权限和必要交互。

## 来源与复用基线

前端从官方 `vbenjs/vue-vben-admin` 正式 Ant Design Vue 应用同步必要工作区，保留一个 `@vben/web-antd` 工程。固定来源、提交及必要适配见[上游记录](../../web/UPSTREAM.md)，完整依赖与工具链以本项目清单及锁文件为准。

TypeApp 的业务接口、权限和页面标准由本仓库维护，自有业务封装不作为 Vben 官方能力。第三方来源及许可归属记录在[上游记录](../../web/UPSTREAM.md)和根 NOTICE 中，运行与构建不依赖相邻检出目录。

实施前核对锁定 Vben 版本的真实导出、官方示例与配套 Ant Design Vue 适配。优先复用认证布局、应用布局、Logo、导航、用户入口、表单、表格集成、抽屉、弹窗和偏好设置；已有公共能力通过配置、事件和插槽接入。缺失适配按实际需要引入并保留版本与许可证，避免复制源码形成另一套通用组件。设备注册、应用授权等业务专用组件按实际需要保留。

## 双端入口与功能导航

主域名默认进入 `/#/system/login`，使用可搜索分页的客户选择和账号密码；子域名及 `/s/{saas_id}/` 固定客户后只输入账号密码。Platform 使用 `/#/platform/login` 和独立身份，System 与 Center 共用当前客户的 System 会话。共用视觉组件不改变身份域或数据范围；个人资料通过原生用户入口访问。

菜单以功能组和二级页面组织，通过 Vben 嵌套路由、树形导航及元信息保持选中项、父级展开、面包屑和标签页一致。页面按下表归属，菜单绑定已登记能力并由平台维护；详情与流程子页可以不占用菜单项，但保留父级关系。

平台维护的目录与当前权限决定可见页面，空组隐藏，父组不产生业务权限。支持深链接、刷新、浏览器前进后退、折叠菜单和窄屏。更换客户登录入口、账号域或权限变化后同步清理旧页面数据、请求及失效导航；API 继续独立校验授权。

### 菜单和页面归属

| 工作区 | 功能分组 | 页面职责 |
| --- | --- | --- |
| Platform | 客户与物联 | Tenant、客户超管、注册资格签发、全局设备资产、接入应用和跨客户转配 |
| Platform | 平台权限 | 平台用户、平台角色、平台及共享子系统菜单 |
| Platform | 运维监控 | MQTT 全局资源、授权、节点、配置、配额、调试、运行概览及审计 |
| Platform | 平台设置 | 平台品牌与主题、System 公共登录和新客户初始模板、运行配置 |
| System | 用户与权限 | 当前 Tenant 的独立用户、角色和角色菜单授权 |
| System | 系统管理 | 当前 Tenant 品牌、默认主题及操作审计 |
| Center | 物联中心 | 当前 Tenant 的分类、设备、已分配注册资格、接入应用、通信授权、连接观察及转配接收 |

两端可复用 Vue 文件，但标题、数据语义和动作权限分别取自对应工作区。个人资料保留自己的入口，设备详情和逐设备授权通过所属业务页面进入，不增设一级菜单。当前入口与业务行为见[物联中心](../guide/iot-center.md#准备后端与人员账号)。

## 页面组成

两端共用 Vben 导航、布局、主题、请求处理与配套控件。列表按现有页面、表单和表格集成组织标题、主要动作、搜索、工具栏及分页；业务需要统计区、页签或回收站时沿用原生组合方式。具体业务内容按本项目模块职责维护。

列表使用表格标题，详情与配置使用 `Page` 标题，同一区域不重复放置相同标题。标题、字段标签、正文、辅助说明与统计数值分别消费原生 `Page`、`Card`、表单、`Descriptions`、主题文本 token 和 `Statistic` 的字号及字重，不使用全局 CSS 重设第三方控件。业务辅助说明采用 `text-sm` 与语义颜色；长标识和 Topic 可换行，必要时使用等宽字体，不挤压操作区域。

查询使用表格内置表单的一至三列响应布局；编辑表单使用纵向标签，文本、选择与数值控件填满所属栅格，开关保持原生宽度。配置按品牌、主题时间、布局导航或后端声明的业务组组织。页面及卡片间使用原生间距与 `gap-4`、`mb-4` 等标准间距，不叠加重复卡片内边距。需要分页而总数未知的协议资源和审计使用表格 `pager` 插槽保留游标语义，不伪造记录总数。

次要行操作使用配套 `Dropdown`，主要动作保留直接入口，危险动作仍需确认。证书与 CRL 管理使用原生页签和折叠面板分组，输入保留可见标签。加载表单时使用保留子组件的 `Spin`；不能通过卡片骨架卸载表单，再等待该表单接收接口结果。

| 范围 | 统一要求 |
| --- | --- |
| 搜索筛选 | 使用 Vben 表单或表格的查询集成，字段及文案按业务含义定义；查询、重置、响应布局和间距沿用原生配置。 |
| 下拉选项 | 使用配套选择器的宽度、浮层和长文本处理能力，确保内容在视口内可辨识和可操作。 |
| 表格 | 使用 Vben 表格集成及配套控件能力处理列宽、横向滚动、分页、排序、状态、空数据与加载状态，保留稳定分页和必要字段可读性。 |
| 行操作 | 按业务权限配置按钮与原生下拉菜单；长文本及窄屏下可操作，危险动作保留明确确认。 |
| 编辑表单 | 使用 Vben 表单和配套控件，字段、必填项与后端契约一致。采用原生抽屉或弹窗承载编辑，响应布局遵循组件能力。 |
| 简短详情 | 使用原生弹层与配套字段展示，长内容可读，只读详情不展示保存按钮。设备详情使用独立页，展示资料、当前使用关系、期限、连接及授权生效状态。 |
| 主题与响应布局 | 布局、卡片、图表、标签、空状态和浮层通过 Vben 及 Ant Design Vue 主题机制支持亮色、暗色与主题色；字体、圆角、间距和层级沿用原生 token。 |

已移除被原生能力覆盖的 `CrudSearchField`、`CrudTableActions`、`AppDrawer` 和独立尺寸工具；设备通信、授权和一次性秘密展示继续由业务维护。通过原生配置满足业务可用性，不强制四字标签、自建行操作布局或全局覆盖控件内部 CSS。

## 弹层与异步行为

弹层的尺寸、视口限制、内边距、标题和保存/取消区沿用 Vben 原生配置。通过组件生命周期处理提交状态及必要的未保存输入保护；保存中避免关闭导致操作结果不明，详情关闭不引入额外业务提交。

搜索、刷新、保存、登录、导出、同步和批量操作等异步动作都有执行中反馈和重复提交保护。行操作等待返回的 Promise，处理期间避免同一行发起冲突动作；失败后释放执行状态并保留可修正的输入。搜索与重置避免使筛选条件和显示结果错位。

成功、失败、空数据、加载中和无权限使用一致的文案与呈现规则。设备生命周期、连接状态与授权生效状态分别展示，保存成功不等于活动连接已撤权。原始通信投递也不表示设备已经完成业务处理。

## Web 主题与站点设置

接通 Vben 原生偏好设置，使用亮色、暗色、跟随系统、主题色以及已接通的布局、导航、侧栏、面包屑、标签页和页脚选项。设置项必须产生实际效果，布局和业务控件使用一致主题；删除重复主题色选择器与强制关闭偏好的路径。没有业务接入的功能入口不作为可用设置暴露。

平台维护自身品牌、主题及 System 公共登录与新客户初始模板；各 Tenant 超管维护本系统品牌和默认主题。设置由所属域授权控制，具备数据库保存、公开白名单、并发版本与审计；初始模板只在开通时拷贝。运行配置由 `/platform/configuration` 管理。

项目显示名称默认 TypeApp，官网说明或链接使用 https://iots.top。官网信息不参与业务域名、API、回调、监听或 Host 白名单。各端登录、布局品牌和动态标题消费当前端配置，品牌资源失效时使用本地默认标识和名称；关键界面不依赖第三方演示资源。

个人偏好在当前浏览器按身份域、Tenant、账号及模拟操作者隔离，只保存显式修改字段。优先级为个人显式覆盖、当前端默认值、Vben 缺省值；未登录页使用当前入口的公开配置，品牌及身份字段不允许个人覆盖。复用原生偏好更新和恢复能力，不增加跨设备同步。

“恢复默认”清除个人覆盖并采用最新站点默认值；与原生“清理缓存并退出”动作明确区分，单侧退出保持另一身份会话。Web 设置保存后更新保存者界面，其他页面在下次读取或刷新时生效，无须服务重启。读取失败提供有效缺省及重试反馈。服务启动参数仍按原保存、校验和实际生效契约处理。

## 接口与权限衔接

页面统一调用模块接口封装，由公共请求层处理 TypeApp 的响应、认证失败和错误信息。菜单、路由和按钮与后端权限定义一致，接口本身继续校验授权与数据范围。字段、枚举、时间格式及错误码随本项目接口契约统一。

范围仅包括页面与交互。外部项目的响应封装、框架注解、插件扫描和后端发布流程不因此成为 TypeApp 的新增契约。

运行观察区域可见时每 5 秒轮询，页面隐藏或离开时暂停，不叠加未完成请求；显示观察时间、刷新中及失败状态，不能将刷新失败显示成设备确定离线。时间统一存为 UTC，按用户时区展示。

列表默认每页 20 条、最多 100 条，按实际接口支持设备、分类、客户或时间筛选，保持明确排序与稳定分页。协议资源使用绑定身份、范围和筛选条件的游标；筛选变化后重置游标。运行概览展示连接、协议积压、拒绝及故障状态，不提供遥测历史或业务指标。

注册码、设备凭据和应用密钥仅在对应创建或重置结果中一次性交付，关闭弹层后从页面状态清除，不在普通详情中回显。响应未知时先查实际状态，不能自动重复签发。Demo 保留查询、分页与详情，全部写动作受环境和权限共同限制。

## 页面验收

每类页面使用真实业务数据和失败场景核对搜索、分页、编辑、详情、异步反馈及权限；适用时检查导出与批量操作。统一检查亮色、暗色、跟随系统、主题色、已开放布局和窄屏，包含键盘可达、长名称、多行内容、空数据及权限不足状态。

新增导航、主题和配置验收覆盖双域登录与单侧退出、分组过滤、深链接、登录前客户选择与固定入口、模拟退出、偏好刷新恢复与重置，以及设置保存后真实页面生效。验证个人覆盖优先级、公开字段白名单、越权拒绝、并发冲突和图片失效；旧浏览器缓存不能继续隐藏品牌与设置入口。不重复测试 Vben 内部算法或固定 CSS 实现细节。

前端实现完成后运行实际配置的类型检查与生产构建，并在真实浏览器验收适用交互；代码或构建通过不能代替页面验收。涉及后端和持久化的变更，沿用编译应用入口与 MySQL、PostgreSQL、SQLite 的真实语义验证。新增行为优先本地 macOS 验收，再集中验证其他正式平台；当前结果进入同源标准项目，证据分别记录实际范围。本页是实现与验收依据，不代表相应页面已经完成。
