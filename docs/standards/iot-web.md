# 物联网中心 Web 页面标准

本标准适用于物联网中心的平台管理端和 SaaS 用户端。通用 UI 优先直接复用 Vben Admin Pro 的组件、样式与配置机制，以锁定依赖的公开接口为准；应用补充业务字段、接口、权限和必要交互。

## 来源与复用基线

参考项目的 `web/README.md` 与包配置标明 Vue Vben Admin `5.6.0`，单应用 `@vben/web-antd`，来源为 `vbenjs/vue-vben-admin`；锁文件中的 Vue 为 `3.5.35`、Ant Design Vue 为 `4.2.6`，包管理器为 `pnpm@10.28.2`。这些是参考项目的版本；实际引入源码与依赖时按本项目锁文件固定完整版本。

参考项目的[前端对应规则](https://github.com/zoujingli/SmartAdminDeveloper/blob/a61c041a1c3d9f6a44d5c4da4ef55b1f18a5f39d/AGENTS.md#前端对应规则)、[前端接入说明](https://github.com/zoujingli/SmartAdminDeveloper/blob/a61c041a1c3d9f6a44d5c4da4ef55b1f18a5f39d/docs/开发指南/前端接入.md)及公共组件用于说明现有代码来源。运行与构建不依赖相邻检出目录。当前引入范围见[上游记录](../../web/UPSTREAM.md)，不能将参考项目或本项目的自定义封装一律标为官方组件。

实施前核对锁定 Vben 版本的真实导出、官方示例与配套 Ant Design Vue 适配。优先复用认证布局、应用布局、Logo、导航、用户入口、表单、表格集成、抽屉、弹窗和偏好设置；已有公共能力通过配置、事件和插槽接入。缺失适配按实际需要引入并保留版本与许可证，避免复制源码形成另一套通用组件。设备物模型等业务专用组件可以保留。

## 双端入口与功能导航

SaaS 用户端是默认登录入口，平台管理端拥有独立入口、账号和权限体系。共用视觉组件不改变身份域、会话及租户数据范围；页面清楚呈现所在模块和当前工作区。登录后进入真实可用且获准的业务入口，个人资料通过 Vben 用户入口访问。

菜单以功能组和二级页面组织，通过 Vben 嵌套路由、树形导航及元信息保持选中项、父级展开、面包屑和标签页一致。管理端按客户、设备、系统和运维分组；用户端按设备、数据、告警、系统和运维分组，具体页面归类见[当前实现说明](../development/current-implementation-alignment.md#菜单和页面归属)。详情与流程子页可以不占用菜单项，但保留父级关系。

固定菜单目录与当前权限决定可见页面，空组隐藏，父组不产生业务权限。支持深链接、刷新、浏览器前进后退、折叠菜单和窄屏。切换租户、账号域或权限变化后同步清理旧页面数据、请求及失效导航；API 继续独立校验授权。

## 页面组成

两端共用 Vben 导航、布局、主题、请求处理与配套控件。列表按现有页面、表单和表格集成组织标题、主要动作、搜索、工具栏及分页；业务需要统计区、页签或回收站时沿用原生组合方式。具体业务内容按本项目模块职责维护。

| 范围 | 统一要求 |
| --- | --- |
| 搜索筛选 | 使用 Vben 表单或表格的查询集成，字段及文案按业务含义定义；查询、重置、响应布局和间距沿用原生配置。 |
| 下拉选项 | 使用配套选择器的宽度、浮层和长文本处理能力，确保内容在视口内可辨识和可操作。 |
| 表格 | 使用 Vben 表格集成及配套控件能力处理列宽、横向滚动、分页、排序、状态、空数据与加载状态，保留稳定分页和必要字段可读性。 |
| 行操作 | 按业务权限配置按钮与原生下拉菜单；长文本及窄屏下可操作，危险动作保留明确确认。 |
| 编辑表单 | 使用 Vben 表单和配套控件，字段、必填项与后端契约一致。采用原生抽屉或弹窗承载编辑，响应布局遵循组件能力。 |
| 简短详情 | 使用原生弹层与配套字段展示，长内容可读，只读详情不展示保存按钮。复杂设备详情使用独立页，组织基本信息、当前数据、历史曲线、指令、告警和审计。 |
| 主题与响应布局 | 布局、卡片、图表、标签、空状态和浮层通过 Vben 及 Ant Design Vue 主题机制支持亮色、暗色与主题色；字体、圆角、间距和层级沿用原生 token。 |

原 `CrudSearchField`、`CrudTableActions`、`AppDrawer` 和独立尺寸工具按实际调用者及上游能力逐项替换；官方能力覆盖后删除失去用途的实现与样式。通过原生配置满足业务可用性，不继续强制四字标签、自建行操作布局或全局覆盖控件内部 CSS。

## 弹层与异步行为

弹层的尺寸、视口限制、内边距、标题和保存/取消区沿用 Vben 原生配置。通过组件生命周期处理提交状态及必要的未保存输入保护；保存中避免关闭导致操作结果不明，详情关闭不引入额外业务提交。

搜索、刷新、保存、登录、导出、同步和批量操作等异步动作都有执行中反馈和重复提交保护。行操作等待返回的 Promise，处理期间避免同一行发起冲突动作；失败后释放执行状态并保留可修正的输入。搜索与重置避免使筛选条件和显示结果错位。

成功、失败、空数据、加载中和无权限使用一致的文案与呈现规则。设备连接状态、遥测新旧和指令执行状态以已确认的业务含义展示，不能用按钮请求成功代替设备操作成功。

## Web 主题与站点设置

接通 Vben 原生偏好设置，使用亮色、暗色、跟随系统、主题色以及已接通的布局、导航、侧栏、面包屑、标签页和页脚选项。设置项必须产生实际效果，布局和业务控件使用一致主题；删除重复主题色选择器与强制关闭偏好的路径。没有业务接入的功能入口不作为可用设置暴露。

平台站点设置包含名称、说明、品牌资源、默认时区、页脚信息和默认界面偏好，由独立授权控制，并具备数据库保存、白名单校验、版本冲突处理及审计。公开读取仅返回允许展示的站点信息和默认偏好。该责任继续衔接 ，避免建设第二套配置服务。

项目显示名称默认 TypeApp，官网说明或链接使用 https://iots.top。官网信息不参与业务域名、API、回调、监听或 Host 白名单。两端登录、布局品牌和动态标题消费同一站点信息，品牌资源失效时使用本地默认标识和名称；关键界面不依赖第三方演示资源。

个人偏好在当前浏览器按账号和模块保存。可个性化字段按个人显式覆盖、站点默认值、Vben 应用缺省值的顺序生效；未登录页使用公开站点默认值，名称和品牌保持站点设置权威。复用 Vben 缓存和偏好更新能力，只补范围与默认值衔接，不增加跨设备同步或租户独立品牌。

“恢复默认”清除个人覆盖并采用最新站点默认值；与原生“清理缓存并退出”动作明确区分，单侧退出保持另一身份会话。Web 设置保存后更新保存者界面，其他页面在下次读取或刷新时生效，无须服务重启。读取失败提供有效缺省及重试反馈。服务启动参数仍按原保存、校验和实际生效契约处理。

## 接口与权限衔接

页面统一调用模块接口封装，由公共请求层处理 TypeApp 的响应、认证失败和错误信息。菜单、路由和按钮与后端权限定义一致，接口本身继续校验授权与数据范围。字段、枚举、时间格式及错误码随本项目接口契约统一。

范围仅包括页面与交互。外部项目的响应封装、框架注解、插件扫描和后端发布流程不因此成为 TypeApp 的新增契约。

当前数据区域可见时每 5 秒轮询，页面隐藏或离开时暂停，不叠加未完成请求；显示数据时间、刷新中及失败状态，不能将刷新失败显示成设备确定离线。时间统一存为 UTC，按用户时区展示。历史查询默认单设备最近 24 小时，支持 7 天原始数据及 90 天分钟聚合，采用服务端分页。

列表默认每页 20 条、最多 100 条，支持设备、产品、时间与模型字段筛选，并保持明确排序与稳定分页。单图最多 2000 个点，超出时服务端按时间桶降低显示密度并标示实际粒度；原始记录仍可分页查询，缺测显示为空。运行概览展示接收速率、确认延迟、连接数、积压、拒绝数及故障状态。

历史遥测以异步 CSV 任务导出，保持当前筛选条件和授权范围；单次最多 100000 行或 100 MiB，每租户最多 2 个并行任务、全局最多 10 个，等待队列有界且可取消。预计超限时拒绝并提示缩小范围，实际触及限制时明确失败，不截断后标为成功。文件保留 24 小时，每次下载重新检查当前租户及权限，对可能被表格软件执行的单元格作安全文本处理；日期、单位与状态文案和页面一致。提供确认、任务状态及失败反馈，不在浏览器拉取全量遥测后生成文件。完整参数与验证入口见[导出说明](../development/iot-exports.md)。需要上传时由公共上传入口管理进度与错误，具体存储协议按本项目能力确定。

## 页面验收

每类页面使用真实业务数据和失败场景核对搜索、分页、编辑、详情、异步反馈及权限；适用时检查导出与批量操作。统一检查亮色、暗色、跟随系统、主题色、已开放布局和窄屏，包含键盘可达、长名称、多行内容、空数据及权限不足状态。

新增导航、主题和配置验收覆盖双端登录与单侧退出、分组过滤、深链接、租户切换、偏好刷新恢复与重置，以及设置保存后真实页面生效。验证个人覆盖优先级、公开字段白名单、越权拒绝、并发冲突和图片失效；旧浏览器缓存不能继续隐藏品牌与设置入口。不重复测试 Vben 内部算法或固定 CSS 实现细节。

前端实现完成后运行实际配置的类型检查与生产构建，并在真实浏览器验收适用交互；代码或构建通过不能代替页面验收。涉及后端和持久化的变更，沿用编译应用入口与 MySQL、PostgreSQL、SQLite 的真实语义验证。新增行为优先本地 macOS 验收，再集中验证其他正式平台；当前结果进入同源标准项目，证据分别记录实际范围。本页是实现与验收依据，不代表相应页面已经完成。
